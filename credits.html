The image model runs in your browser. Only the app and model files are fetched online; your photo is not uploaded or stored by this page.

BiRefNet Lite 512

Cutout loads the browser-ready FP16 ONNX model studioludens/birefnet-lite-512 from Hugging Face at run time. The model repository identifies the model as MIT-licensed and attributes it to:

  • Copyright © 2024 ZhengPeng
  • Copyright © 2026 Studio Ludens V.O.F.

Read the MIT license · Model card and details

The model accepts `input_image` at 512 × 512 and emits a single-channel mask as `output_image` at 512 × 512. The mask is resized to match the source PNG dimensions; this does not add inference detail.

Transformers.js 3.7.2

The app loads Transformers.js from jsDelivr at run time. The pinned package identifies its license as Apache-2.0.
